# Phase 3: Strings

This phase covers Java `String`, common string operations, mutable text with `StringBuilder` and `StringBuffer`, and small text-processing projects.

## Running an example

From the directory containing a Java file:

```bash
javac StringBasics.java
java StringBasics
```

Each example is independent and uses the default package so it can be compiled directly.

## Topics

- `src/basics`: String creation, immutability, pooling, and comparison
- `src/methods`: Frequently used String methods
- `src/builders`: Mutable text with StringBuilder and StringBuffer
- `src/practice`: Small programs that process words and text
- `notes`: Short explanations and revision notes
