# Common String Methods

| Method | Purpose |
| --- | --- |
| `length()` | Returns the String length |
| `isEmpty()` | Checks whether the length is zero |
| `isBlank()` | Checks whether the String is empty or whitespace |
| `charAt(index)` | Returns a character |
| `contains(value)` | Checks for a sequence |
| `indexOf(value)` | Finds the first index |
| `substring(start, end)` | Extracts part of a String |
| `replace(old, new)` | Replaces literal text |
| `split(regex)` | Divides text into an array |
| `trim()` | Removes leading and trailing ASCII spaces |
| `strip()` | Removes leading and trailing Unicode whitespace |
| `equals(value)` | Compares contents |
| `compareTo(value)` | Compares lexicographically |

Most String methods return a new String because Strings are immutable.
