# Java Fundamentals

This README contains beginner-friendly notes covering the basics of
Java, from what Java is to how a Java program is compiled and executed.

## 1. What is Java?

Java is a high-level, object-oriented programming language originally
developed by Sun Microsystems and now maintained by Oracle.

### Main Features of Java

-   Platform independent --- "Write Once, Run Anywhere"
-   Object-oriented
-   Secure
-   Robust
-   Supports multithreading
-   Automatic memory management through Garbage Collection

Java source code is compiled into **bytecode**, which is executed by the
**JVM (Java Virtual Machine)**.

------------------------------------------------------------------------

## 2. JDK vs JRE vs JVM

  -----------------------------------------------------------------------
  Component               Full Form               Main Purpose
  ----------------------- ----------------------- -----------------------
  **JDK**                 Java Development Kit    Used to develop Java
                                                  programs

  **JRE**                 Java Runtime            Provides the runtime
                          Environment             environment for Java
                                                  applications

  **JVM**                 Java Virtual Machine    Executes Java bytecode
  -----------------------------------------------------------------------

### Relationship

``` text
JDK
 └── JRE
      └── JVM
```

-   **JDK** = Development tools + runtime components
-   **JRE** = Runtime environment + JVM
-   **JVM** = Executes bytecode

> Note: Modern Java distributions do not always package a separate JRE,
> but the conceptual distinction is useful for learning.

## 3. Java Compilation and Execution

When you write a Java program, it goes through two main stages:

``` text
Java Source Code
      ↓
    javac
      ↓
  Bytecode
      ↓
  .class file
      ↓
    JVM
      ↓
 Program Output
```

### Compilation

The Java compiler `javac` converts `.java` source code into `.class`
bytecode.

``` bash
javac Hello.java
```

### Execution

The `java` command launches the JVM and runs the compiled class.

``` bash
java Hello
```

------------------------------------------------------------------------

## 4. `.java` → `.class` → JVM

Consider a file named:

``` text
Hello.java
```

Compile it:

``` bash
javac Hello.java
```

This generates:

``` text
Hello.class
```

Then run:

``` bash
java Hello
```

The complete flow is:

``` text
Hello.java
    │
    │ javac Hello.java
    ↓
Hello.class
    │
    │ java Hello
    ↓
   JVM
    ↓
Program Output
```

-   `.java` → Java source code
-   `.class` → Compiled Java bytecode
-   JVM → Executes the bytecode

------------------------------------------------------------------------

## 5. Bytecode

**Bytecode** is the intermediate code generated by the Java compiler.

For example:

``` text
Hello.java
    ↓
  javac
    ↓
Hello.class
```

The `.class` file contains bytecode that can be executed by a JVM.

This helps Java achieve platform independence:

``` text
             Bytecode
                │
      ┌─────────┼─────────┐
      ↓         ↓         ↓
 Windows JVM  Linux JVM  macOS JVM
      ↓         ↓         ↓
    Runs      Runs      Runs
```

The same Java bytecode can run on different operating systems when a
compatible JVM is available.

------------------------------------------------------------------------

## 6. JVM Architecture Overview

The JVM is responsible for loading and executing Java bytecode.

A simplified view of the JVM is:

``` text
                    JVM
                     │
          ┌──────────┴──────────┐
          │                     │
    Class Loader        Runtime Data Areas
                                │
             ┌──────────────────┼──────────────────┐
             │                  │                  │
           Heap               Stack          Method Area
             │
             └──────────────────┐
                                ↓
                       Execution Engine
                                │
                     ┌──────────┴──────────┐
                     │                     │
                Interpreter                JIT
```

### Main Components

#### 1. Class Loader

Loads `.class` files into the JVM.

#### 2. Runtime Data Areas

The JVM uses different memory areas, including:

-   Heap
-   Stack
-   Method Area
-   Other runtime areas

#### 3. Execution Engine

Executes bytecode.

It can use:

-   **Interpreter** --- executes bytecode instructions
-   **JIT (Just-In-Time) Compiler** --- compiles frequently executed
    code into native machine code to improve performance

## 7. Stack vs Heap

  -----------------------------------------------------------------------
  Stack                               Heap
  ----------------------------------- -----------------------------------
  Stores method call information and  Stores objects and their instance
  local variables                     data

  Each thread has its own stack       Shared among threads

  Contains stack frames for method    Contains dynamically created
  calls                               objects

  Automatically managed as methods    Managed by the Garbage Collector
  enter and exit                      
  -----------------------------------------------------------------------

### Example

``` java
Student s = new Student();
```

Conceptually:

``` text
Stack                    Heap
┌────────────┐          ┌──────────────┐
│ s ─────────┼─────────→│ Student      │
└────────────┘          │ object       │
                        └──────────────┘
```

The reference variable `s` is associated with the current method's stack
frame, while the `Student` object is created on the heap.

## 8. Java Installation and IDE

To develop Java programs, install a **JDK**.

### Verify Java Installation

Open a terminal or command prompt and run:

``` bash
java -version
```

Then check the Java compiler:

``` bash
javac -version
```

If both commands work, Java is available from your command line.

### Popular Java IDEs

You can use any of these:

-   IntelliJ IDEA
-   Eclipse
-   Apache NetBeans
-   Visual Studio Code with Java extensions

You can also write Java programs using a simple text editor and compile
them from the command line.

## 9. `javac` and `java`

The commands `javac` and `java` have different purposes.

### `javac`

`javac` is the Java compiler.

It compiles Java source code:

``` bash
javac Hello.java
```

Output:

``` text
Hello.class
```

### `java`

`java` launches the JVM and runs the compiled class:

``` bash
java Hello
```

Usually, do **not** run:

``` bash
java Hello.class
```

Instead, specify the class name:

``` bash
java Hello
```

## 10. First Java Program

Create a file named:

``` text
Hello.java
```

Add the following code:

``` java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

### Compile

``` bash
javac Hello.java
```

### Run

``` bash
java Hello
```

### Output

``` text
Hello, World!
```

### Important

The filename must match the public class name:

``` text
Hello.java
    ↓
public class Hello
```

## 11. `main()` Method

The traditional entry point for a Java application is:

``` java
public static void main(String[] args)
```

Let's understand each part.

### `public`

Makes the method accessible to the JVM.

### `static`

Allows the method to be called without creating an object of the class.

### `void`

Means the method does not return a value.

### `main`

The conventional method name used as the application entry point.

### `String[] args`

An array containing command-line arguments passed to the program.

### Example

``` java
public class Demo {
    public static void main(String[] args) {
        System.out.println("Java");
    }
}
```

Run it using:

``` bash
java Demo
```

The application starts by invoking the `main()` method.
